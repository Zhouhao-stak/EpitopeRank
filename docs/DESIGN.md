# EpitopeRank 前端设计规范

## 产品与使用场景
以桌面科研工作为主，支持窄屏查看和操作。主要路径是项目导入 → 数据映射 → 分析进度 → 事件/基因探索 → 图表与报告；肽预测支持独立输入。所有结果保留研究用途语义，不将结合预测描述为免疫原性验证。

## 视觉规范
- 背景 #f5f7f8，内容表面 #ffffff，辅助表面 #edf4f3。
- 正文 #172f39，次级文字 #455f69，提示 #60737c。
- 主操作 #087e72，错误 #b33449，边框 #d9e3e6。
- 深色侧栏 #142e38，选中项 #284b53；图标采用统一 24px 线性 SVG。
- 字体 Segoe UI / Microsoft YaHei / system-ui；数据与序列使用等宽字体或 tabular-nums。
- 页面标题 28px，移动端 25px；正文 14px；控制项至少 34–40px 高。
- 页面内容间距 24–32px，按钮圆角 7px，区块圆角 12px。静态内容不悬浮、不发光。

## 页面结构
- 工作台：入门操作、三步流程、项目统计、当前任务、历史项目。
- 分析流程：进度摘要与阶段列表，清楚区分等待、运行、完成。
- 事件：搜索和筛选在上，数据表与分页在下；移动端保留列宽，在表格区域横向滚动。
- 可视化：桌面左侧限定高度的可滚动图表目录、右侧预览；窄屏使用图表下拉选择器，预览紧随其后。
- 基因：以搜索为核心，保留提示和空结果区域。
- 报告：导出操作、结果区域、报告内容说明。
- 候选新抗原：检查数据、生成候选、高级工具渐进展开。
- 肽预测：输入/HLA、参数、结果、项目生成入口。
- 设置：模型服务与 MCP 工具分区，密码输入不展示现有密钥。

## 交互与维护
导航使用原生按钮、aria-current 和 SVG；手机提供展开菜单。新建项目弹窗支持焦点约束、焦点恢复、Escape 关闭。键盘用户可以跳到内容区域。保留减少动态效果设置。
实现仍由 epitoperank/interface/web_ui.py 提供，保持零构建部署和现有 API。本次没有引入远程字体或图标依赖。

## 验证与发布边界
18 个桌面/手机空状态视图经过浏览器渲染；验证导航、示例填充和无横向溢出。API 使用空状态测试响应，不代表真实预测、导入、报告导出或在线服务已通过验收。
发布前必须用真实项目复核数据填充、长文本、导入失败、分析失败、图表加载及 HTML/PDF 下载；新文案仍需补齐英语词典并做三语言验收。安装更新、服务部署、模型服务连接、第三方服务条款等属于产品发布验收，不能仅凭界面改版宣称可上架。


## 流动交互层
用户明确要求滑动与液态效果，允许在操作界面引入克制的玻璃与光场表现。
- 核心动作：导航标记在功能位置之间滑动（420ms），页面以导航顺序进行 230ms 方向过渡；快速重复切换会取消上一段页面动画。
- 首页：有限范围内的指针光场与液态轮廓，只有鼠标移动才更新，requestAnimationFrame 合并事件，无常驻动画循环。
- 反馈：按钮按压波纹、图表选中态、展开内容短过渡。
- 手机：菜单滑入、遮罩、关闭按钮、Escape；打开时背景 inert，关闭后恢复可操作状态。
- 快捷跳转：Ctrl/⌘ K 或顶部按钮，支持搜索页面与键盘导航，原生 dialog 约束焦点。
- 动态控制：本地保存开关，系统减少动态设置优先；关闭时取消 Web Animations 与 CSS 动画，保留选中态、颜色及文本反馈。
- 禁止将这些效果扩散到表格行、序列字符或预测数值上；不引入 WebGL、第三方动画运行库或远程资产。
- 回归脚本覆盖窄屏菜单、快捷搜索、动态开关及系统减少动态设置。录屏使用空项目 API 测试响应，不代表实际分析性能测试。


## 展示玻璃层（2026-11-05）
首页主视觉采用深海蓝绿背景与半透明流程玻璃面板，研究数据区域保持浅色易读。主视觉使用剪接路径 SVG 线条动效，沿用指针光场和动态关闭设置。按钮增加悬停、按压反馈；真实 fetch 请求期间显示顶部不定进度条，同步点击发起请求的按钮显示忙碌状态，请求完成或失败均清除。移动端主视觉单列。无远程资产或新依赖。浏览器以模拟空 API 检查桌面与 390px 页面，窄屏无横向溢出；不代表真实分析链路验收。


## 华丽深色玻璃主题（2026-11-05）
用户要求强化整体视觉表现。当前覆盖主题采用背景 #060d18、正文 #eaf4ff、次级正文 #b0c4d9、青绿主色 #82eed8、冰紫辅助光场。统一侧栏、KPI、表格、输入、弹窗与按钮的深色半透明表面。增加引导区缓慢光带和主按钮悬停折射，系统减少动态和本地关闭动态均优先。保留 P0 数据优先布局与数值呈现。


## Auros 深海终端主题（2026-11-05，当前视觉规范）
本节覆盖上文旧主题的配色与表面规则。参考用户提供的 Downloads/docs/DESIGN.md，将其视觉语言适配科研操作界面。
- 画布 #012624，凹进表面 #011d1c，内容表面 #003734，交互表面 #064b46；取消玻璃模糊与投影。
- 标题 #ffffff，正文 #edfffe，辅助文字 #bbc7c6，弱提示 #9bb6b2；统计值 #fde9ff。
- 主按钮使用 #cbfffc → #edfffe → #fffdfa → #fad1ff 渐变，深色文字；渐变仅限操作按钮。
- 区块圆角 16px，按钮和输入 6px；标题中等字重和紧凑字距，表格保持原有信息密度与等宽数据策略。
- 首页使用内联 SVG 球面粒子几何，静态呈现，无外部资产、字体或运行依赖。保留现有导航、动态开关、键盘与移动端行为。
- 验证：6 项现有 UI 回归测试通过；Edge 无头浏览器渲染 1440px 桌面、390px 手机空状态，手机无页面横向溢出。截图位于 out/auros-ui。空响应预览不代表真实分析链路验收。
